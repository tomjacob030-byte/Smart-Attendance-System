# Smart Attendance System using Face Recognition

## Description
A Python-based Smart Attendance System that uses face recognition to identify students and automatically mark attendance.

## Features
- Face Detection
- Face Recognition
- Automatic Attendance Marking
- Attendance Storage in CSV

## Technologies Used
- Python
- OpenCV
- face_recognition
- NumPy
- Pandas

## How to Run
1. Install required libraries.
2. Add student images to the ImagesAttendance folder.
3. Run attendanceproject.py.
4. Attendance will be recorded automatically.
